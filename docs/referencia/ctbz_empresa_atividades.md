# ctbz empresa atividades

Lista os CNAEs da empresa e os anexos do Simples Nacional

Lista as atividades (CNAEs) cadastradas na Contabilizei, marcando a principal, com o
ramo (serviço ou comércio) e os anexos do Simples Nacional em que cada uma pode ser tributada.

## Uso

```
ctbz empresa atividades
```

## Exemplos

```sh
  ctbz empresa atividades
```

## Flags globais

```
  -h, --help            mostra a ajuda do comando
  -o, --output string   formato de saída: table, json ou csv (padrão: CTBZ_OUTPUT ou table)
```

Veja também: [`ctbz empresa`](ctbz_empresa.md).
